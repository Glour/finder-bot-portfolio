# Управление блэклистом токенов

Документация по работе с блэклистом токенов через админ-панель бота.

## Основные возможности

✅ **Три уровня блокировки:**
- Глобальный мут (все сети)
- Мут в конкретной сети (без адреса)
- Мут конкретного адреса контракта

✅ **Автоматическая нормализация:**
- Короткие названия сетей (BSC, ETH) → полные (binance-smart-chain, ethereum)
- Автоматический lowercase для адресов и сетей

✅ **Защита от ошибок:**
- Невозможно случайно замутить все токены в сети
- Валидация форматов ввода

✅ **Гибкое управление:**
- Постоянные и временные (24 часа) муты
- Массовое добавление токенов
- Группировка в списке по символам

## Доступ к админ-панели

Для входа в админ-панель используйте команду:

```
/admin
```

В открывшемся меню выберите нужное действие.

---

## Типы мутов

Система поддерживает два типа мутов:

1. **Permanent (Постоянный)** - токен блокируется бессрочно
2. **Temporary (Временный)** - токен блокируется на 24 часа

При добавлении токена в блэклист нужно выбрать тип мута.

---

## Способы добавления токенов в блэклист

### 1. Глобальный мут по символу токена

Блокирует токен во **всех сетях** одновременно.

**Формат:**
```
symbol СИМВОЛ_ТОКЕНА
```

**Пример:**
```
symbol AIBOT
```

**Результат:** Токен AIBOT будет заблокирован во всех сетях (BSC, Ethereum, Base и т.д.).

---

### 2. Мут токена в конкретной сети

Блокирует конкретный токен (по символу) только в указанной сети, без необходимости указывать адрес контракта.

**Формат:**
```
symbol_chain СИМВОЛ_ТОКЕНА СЕТЬ
```

**Примеры:**
```
symbol_chain AIBOT BSC
symbol_chain SCAM ETH
symbol_chain FAKE BASE
```

**Результат:** Токен AIBOT будет заблокирован только в сети BSC, но будет доступен в других сетях.

**Когда использовать:**
- Когда токен скам только в одной сети, но легитимен в других
- Когда нужно замутить токен в конкретной сети, но адрес контракта неизвестен
- Когда токен имеет несколько адресов в одной сети и нужно заблокировать все

---

### 3. Мут по конкретной сети и адресу

Блокирует только конкретный адрес контракта в указанной сети.

**Формат:**
```
СЕТЬ АДРЕС_КОНТРАКТА
```

**Примеры:**
```
BSC 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3
ETH 0x1234567890abcdef1234567890abcdef12345678
SOL TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA
```

**Поддерживаемые форматы названий сетей:**

Вы можете использовать как короткие названия (из сигналов), так и полные названия из базы данных:

| Короткое название (сигнал) | Полное название (БД) |
|---------------------------|----------------------|
| BSC | binance-smart-chain |
| ETH | ethereum |
| SOL | solana |
| MATIC | polygon-pos |
| AVAXC | avalanche |
| BASE | base |
| TON | the-open-network |
| ARB | arbitrum-one |
| BLAST | blast |
| TRC20 | tron |
| FTM | fantom |
| OPTIMISM | optimistic-ethereum |

**Примечание:** Система автоматически преобразует короткие названия сетей в полные и приводит всё к нижнему регистру.

---

### 4. Добавление нескольких токенов одновременно

Вы можете добавить несколько токенов за один раз, указывая каждый на новой строке:

```
BSC 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3
ETH 0x1234567890abcdef1234567890abcdef12345678
symbol SCAM
symbol_chain FAKE BSC
BASE 0xabcdef1234567890abcdef1234567890abcdef12
```

---

### Важно: Защита от случайного мута всей сети

**Система НЕ ПОЗВОЛЯЕТ** создать мут, который заблокирует все токены в сети.

❌ **НЕПРАВИЛЬНО:**
```
BSC
```
Это вызовет ошибку, так как не указан адрес контракта.

✅ **ПРАВИЛЬНО:**
```
BSC 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3    (конкретный адрес)
symbol SCAM                                      (глобальный мут токена)
symbol_chain SCAM BSC                           (токен в конкретной сети)
```

## Просмотр блэклиста

Для просмотра текущего блэклиста выберите **"Показать блэклист"** в админ-панели.

### Формат отображения

Блэклист группируется по токенам:

```
AIBOT:
  [Глобальный мут всех сетей] (до 2026-01-24 15:30)
  binance-smart-chain : 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3
  base : 0xdafghdf3

X:
  tron : 0xda67sdf
  base : 0xdafghdf3 (до 2026-01-24 12:00)

Без токена:
  ethereum : 0x123456789 (до 2026-01-23 18:00)
```

**Объяснение:**
- **AIBOT, X** - символы токенов
- **[Глобальный мут всех сетей]** - указывает, что токен заблокирован глобально (во всех сетях)
- **binance-smart-chain : 0x...** - конкретная сеть и адрес контракта
- **(до YYYY-MM-DD HH:MM)** - дата истечения мута (только для временных мутов)
- **Без токена** - записи без привязки к глобальному токену (legacy формат)

---

## Удаление из блэклиста

Для удаления токена из блэклиста:

1. В админ-панели выберите **"Удалить из блэклиста"**
2. Выберите нужный токен из списка
3. Подтвердите удаление

**Примечание:** Временные муты автоматически истекают через 24 часа и не отображаются в списке после истечения срока.

## Примеры использования

### Пример 1: Глобальная блокировка скам-токена

**Ситуация:** Обнаружен скам-токен SCAM, который существует в нескольких сетях.

**Действия:**
1. `/admin`
2. "Добавить в блэклист"
3. "Permanent" (постоянный мут)
4. Ввести: `symbol SCAM`

**Результат:** Токен SCAM заблокирован во всех сетях навсегда.

---

### Пример 2: Временная блокировка токена в одной сети

**Ситуация:** Подозрительная активность токена в сети BSC, нужно заблокировать на 24 часа.

**Действия:**
1. `/admin`
2. "Добавить в блэклист"
3. "Temporary" (временный мут)
4. Ввести: `BSC 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3`

**Результат:** Токен заблокирован только в сети BSC на 24 часа.

---

### Пример 3: Блокировка токена только в одной сети

**Ситуация:** Токен SHADY легитимен в Ethereum, но скам в BSC.

**Действия:**
1. `/admin`
2. "Добавить в блэклист"
3. "Permanent"
4. Ввести: `symbol_chain SHADY BSC`

**Результат:** Токен SHADY заблокирован только в BSC, в Ethereum он остается доступным.

---

### Пример 4: Массовое добавление

**Ситуация:** Нужно заблокировать несколько токенов из одной группы.

**Действия:**
1. `/admin`
2. "Добавить в блэклист"
3. "Permanent"
4. Ввести:
```
BSC 0xda67fbf4e6fa4bb78f62533b7264e1b13295fdf3
ETH 0x1234567890abcdef1234567890abcdef12345678
symbol_chain FAKE BASE
```

**Результат:** Два конкретных адреса и токен FAKE в сети BASE заблокированы.

---

### Пример 5: Комбинированная блокировка

**Ситуация:** Нужно заблокировать токен глобально + несколько конкретных адресов других токенов + один токен только в BSC.

**Действия:**
1. `/admin`
2. "Добавить в блэклист"
3. "Permanent"
4. Ввести:
```
symbol GLOBALSCAM
symbol_chain BSCONLY BSC
BSC 0x111111111
ETH 0x222222222
```

**Результат:**
- Токен GLOBALSCAM заблокирован глобально во всех сетях
- Токен BSCONLY заблокирован только в BSC
- Два конкретных адреса заблокированы в BSC и ETH

## Технические детали

### Автоматическая нормализация

Система автоматически:
- Приводит названия сетей к нижнему регистру
- Преобразует короткие названия сетей (BSC, ETH) в полные (binance-smart-chain, ethereum)
- Приводит адреса контрактов к нижнему регистру
- Приводит символы токенов к верхнему регистру (для глобальных мутов)

### Уведомления администратору

При добавлении токена в блэклист, главный администратор (ID: 0) получает уведомление о том, кто и какой токен добавил.

### Кеширование

Блэклист кешируется в Redis для быстрого доступа.

### Истечение временных мутов

Временные муты автоматически истекают через 24 часа после создания. Истекшие записи не отображаются в списке блэклиста.

## Часто задаваемые вопросы

**Q: В чем разница между глобальным мутом, мутом по сети и мутом по адресу?**

A:
- `symbol TOKEN` - блокирует токен во всех сетях
- `symbol_chain TOKEN CHAIN` - блокирует токен только в указанной сети
- `CHAIN ADDRESS` - блокирует только конкретный адрес контракта в сети

**Q: Можно ли заблокировать один токен частично (в некоторых сетях)?**

A: Да, используйте `symbol_chain TOKEN CHAIN` для каждой нужной сети.

**Q: Как заблокировать токен, если я не знаю его адрес?**

A: Используйте:
- `symbol ТОКЕН` - для блокировки во всех сетях
- `symbol_chain ТОКЕН СЕТЬ` - для блокировки в конкретной сети

**Q: Можно ли случайно заблокировать все токены в сети?**

A: Нет, система защищена от этого. Если вы введете только название сети без адреса, система выдаст ошибку и попросит использовать правильный формат.

**Q: Можно ли продлить временный мут?**

A: Нет, временный мут истекает через 24 часа. Если нужно продлить блокировку, удалите запись и создайте новую.

**Q: Что делать, если токен есть в нескольких сетях, но нужно заблокировать только в некоторых?**

A: Используйте мут по сети и адресу для каждой конкретной сети, не используйте глобальный мут.
